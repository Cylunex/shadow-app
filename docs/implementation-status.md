## 当前限制与下一步

- 0.8.0–0.12.0 的累计代码已部署，手机已安装 0.12.0（22）。真实模型多轮对话、系统语音／分享／保存、后台省电与权限、进程重启后的加密附件恢复仍需真机验收。
- 聊天已支持历史分页、关键词检索与上下文定位。记忆支持全部有效内容检索与分页，手机每页 50 条、单次窗口最多 600 条；0.13.0 源码可检索当前伙伴全部有效事项、每页 50 项且窗口最多 600 项，已安装 0.12.0 及旧服务仍仅最近 100 项；详情最多 20 次执行、100 步计划和 40 份成果。文本预览最多 64000 字符，完整文件可保存／分享。
- 离线缓存仅为最近一次打开聊天的 200 条消息；已完整读取的附件草稿可恢复，读取未完成的附件需重新选择。草稿不跨设备同步。
- 系统语音输入与朗读已实现；服务端伙伴音色、跨设备续播和语音生成打断协同后置。
- 前台有真实生成文本预览；后台是用户开启的周期检查，可能延迟，不是实时推送。
- 源码支持可选统一 OIDC 与自动续期，生产登录仍沿用原 DSH Cookie；设备授权列表及单设备远端撤销未实现。
- 联系人支持归档／恢复，人设可新增、复制、移除、切换、编辑和 JSON 文件交换；联系人永久删除与复杂人设格式后置。角色不是权限隔离单位，没有独立职责沙箱或跨领域任务调度。
- 新能力按 handshake 显示，旧服务仍可使用既有文本聊天。Life／Media 等业务模块、旁支话题和设备桥未纳入本轮。
