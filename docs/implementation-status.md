# Bot 实现记录

2026-11-06；本期仅 Bot，包含初期重建与事项／成果迭代。

## 2026-11-06 后续：黑色界面与附件

已补齐黑色主题、联系人和事项筛选、历史阅读位置保护，以及 Life 通用图片／文件上传、原件预览与保存、系统多附件分享。详见[范围与验证](bot-dark-ui-and-attachments.md)。此批尚未打包、安装或部署，下面 0.7.0 的设备验收属于上一批。

## 已完成

- 在原 shadow-app 仓库替换旧多项目 WebView / Health / Nexus 产品源码、资源和构建入口，保留 Git 历史、本地忽略配置、私有 SDK 与签名资料；未修改其他项目产品代码。
- Kotlin / Compose 原生联系人首页、添加伙伴、持续聊天、事项进度、共享记忆、人设和连接设置。没有“今日”、空间或多业务导航。
- UI / ViewModel / Repository / HTTP 协议分层；纯 Kotlin 核心独立测试，Android 层负责生命周期与 Keystore 加密原子存储。
- 沿用现有 Product v1 的 generation、快照、游标、source/outbox ID 和命令去重；持久待发、原编号重试、回前台恢复、401 重连、跨联系人隔离。
- 在 Losna 最小增加 Bot 联系人创建、人格读写和有效共享记忆读取。联系人保存于原状态库；人设沿用 Personas，记忆沿用 Memory，未增加第二权威。
- 旧超级 App 设计入口及 Losna 协作约定已注明当前范围，避免继续实施过时方案。
- 会话首页支持最近消息、时间、在办事项数量和搜索；事项详情展示计划、近期执行与成果，可在原事项继续或取消后续执行。
- 文本成果沿用既有快照、所属入口和遗忘校验；Android 分享及选中文字进入伙伴草稿，由用户编辑发送。
- 统一消息／事项待发命令，兼容旧版加密状态，保留原命令 ID 与预期版本；冲突不会自动改版本重放。

## 验证结果

- Android `compileDebugKotlin` 通过；Lint 0 错误。固定依赖有升级提示，沿用启动图标有形状提示，均不影响本轮编译。
- 13 项 JVM 核心测试和 1 项跨仓库合成 HTTP 集成测试通过；集成流程运行实际 Losna Runtime / Product / SQLite，模型使用合成回复。
- Losna JavaScript 语法检查及 665 项完整测试通过。
- 0.7.0（15）已沿用原发布签名构建并安装真机，服务端增量已部署。真机通过 HTTPS 登录、联系人与事项详情读取、关闭进程后重启恢复加密会话；真实部署回执和参数仅保存在工作区 operations。

## 当前限制与下一步

- HTTPS 代理路径、生产 DSH 登录与关闭进程后的会话恢复已通过真机检查；复杂布局、键盘、完整系统分享流程、重装／跨设备密钥恢复及真实模型多轮收发仍待进一步验收。
- 消息只展示最近 200 条，记忆只展示最近 100 条有效记录；事项按联系人显示最近 100 项，详情最多 20 次执行、100 个计划步骤和 40 份成果，文本预览最多 64000 字符。历史分页、语音和推送未实现；附件上传已在后续批次补齐，等待发布。
- 新联系人默认沿用已有主模型与服务端能力；角色不是权限隔离单位，不宣称有独立职责沙箱或跨领域任务调度。
- 人设可以新增、选择和编辑；联系人删除／归档、复杂人设导入、设备授权管理后置。
- 连接使用现有 DSH Cookie 到期语义，尚无移动端 refresh token 与设备级撤销。
- 自定义联系人、人设、记忆、事项详情与成果入口按 handshake 能力显示；未部署本轮服务端增量时，原文本聊天仍可使用。
- 初期工程不加载旧产品本地配置，也不自动迁移或删除原 App 的本地业务数据；正式签名已与上一包核对一致。本次设备未安装旧版，属于首次安装，旧数据的覆盖升级尚未实测。
