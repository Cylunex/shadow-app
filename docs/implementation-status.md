# 初期实现记录

2026-11-06；本期仅 Bot。

## 已完成

- 在原 shadow-app 仓库替换旧多项目 WebView / Health / Nexus 产品源码、资源和构建入口，保留 Git 历史、本地忽略配置、私有 SDK 与签名资料；未修改其他项目产品代码。
- Kotlin / Compose 原生联系人首页、添加伙伴、持续聊天、事项进度、共享记忆、人设和连接设置。没有“今日”、空间或多业务导航。
- UI / ViewModel / Repository / HTTP 协议分层；纯 Kotlin 核心独立测试，Android 层负责生命周期与 Keystore 加密原子存储。
- 沿用现有 Product v1 的 generation、快照、游标、source/outbox ID 和命令去重；持久待发、原编号重试、回前台恢复、401 重连、跨联系人隔离。
- 在 Losna 最小增加 Bot 联系人创建、人格读写和有效共享记忆读取。联系人保存于原状态库；人设沿用 Personas，记忆沿用 Memory，未增加第二权威。
- 旧超级 App 设计入口及 Losna 协作约定已注明当前范围，避免继续实施过时方案。

## 验证结果

- Android `compileDebugKotlin` 通过；Lint 0 错误。固定依赖有升级提示，沿用启动图标有形状提示，均不影响本轮编译。
- 8 项 JVM 核心测试和 1 项跨仓库合成 HTTP 集成测试通过；集成流程运行实际 Losna Runtime / Product / SQLite，模型使用合成回复。
- Losna JavaScript 语法检查及 662 项完整测试通过。
- 没有构建 APK、安装真机、修改生产配置或部署服务。

## 当前限制与下一步

- 真机视觉、键盘、进程回收、Android Keystore 恢复、反向代理路径与生产 DSH 登录／模型收发尚待设备及正式环境验收；不把编译和合成集成等同于上线可用。
- 消息只展示最近 200 条，记忆只展示最近 100 条有效记录；历史分页、附件、语音和推送未实现。
- 新联系人默认沿用已有主模型与服务端能力；角色不是权限隔离单位，不宣称有独立职责沙箱或跨领域任务调度。
- 人设可以新增、选择和编辑；联系人删除／归档、复杂人设导入、设备授权管理后置。
- 连接使用现有 DSH Cookie 到期语义，尚无移动端 refresh token 与设备级撤销。
- 自定义联系人、人设和记忆按钮按 handshake 能力显示；未部署本轮服务端增量时，原文本聊天仍可使用，新增入口不会伪装存在。
- 初期工程不加载旧产品本地配置，也不自动迁移或删除原 App 的本地业务数据；后续实际发布前核实原签名与覆盖安装影响。
