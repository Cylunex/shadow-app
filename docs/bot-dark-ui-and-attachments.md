# Bot 黑色界面与 Life 通用附件

2026-11-06。范围是 Shadow App 的 Bot；不新增业务模块、设备控制或新的 Agent 运行时。

## 参考与实际取舍

- 手机 Grok Bot 的联系人首页和聊天页：黑色底、轻量列表、清晰的名字／摘要／时间、灰阶气泡及底部胶囊输入区。只观察页面，不发送消息，不复制私人聊天或品牌素材。
- [Muse 产品设计](https://muse.ai/blog/how-we-designed-muse)：主聊天保持连续，事项、结果和计划可直接查看。详情先呈现结果和成果，执行记录按需展开。
- [Tobs / DeepSeekBot](https://github.com/BotHarness/DeepSeekBot)、[DS Bot](https://github.com/Fei2411/DS-Bot)：参考长期联系人及可持续的工作入口，不引入群聊、第二运行时或新的权限控制面。
- [Grok Bot 文件与成果](https://docs.x.ai/grok-bot/files-and-results)：附件先放进草稿再发送，成果可直接阅读。Shadow 复用自己的现有消息／事项契约。
- 颜色对齐 Shadow Media 的中性灰阶：背景 `#101010`、表面 `#171717`、输入框 `#252525`、本人气泡 `#303030`、主文字 `#F4F4F4`。系统栏及启动窗口保持深色。

## 页面与交互

首页支持搜索、全部／进行中筛选、最近消息排序、草稿提示、待确认操作、空结果恢复；设置和添加伙伴放在顶部。头像使用稳定的灰阶与名字首字，不使用未接入的自定义头像功能。

聊天保留长期会话，事项与成果可一键进入，人设／共享记忆放入菜单。气泡支持日期分隔、选择文字、复制全文和回到最新；反向列表配合稳定消息键，阅读历史时收到新消息不强制跳底。用户主动发送后恢复跟随最新消息。

事项按全部／进行中／已结束筛选，排除已被替代及停止使用的旧事项。详情优先显示最新结果、成果卡片、计划，再提供原事项继续操作；近期执行记录默认折叠。输入区消费系统 Insets，避免键盘与导航栏重复留白。

## 图片与文件

- 输入框加号提供系统图片选择器和文件选择器；支持 Android 单个／多个附件分享。分享先选择伙伴，不自动发送。每条最多 8 个附件，每个 1 字节至 20 MiB。
- 图片支持 JPEG、PNG、GIF、WebP、AVIF；其他类型作为文件原件上传。图片的实际格式由内容识别，不能把任意文件伪装成图片。
- 选择后串行读取和上传，展示等待／上传／失败／已上传待发送，支持移除和原编号重试。上传未完成时不能把含附件的草稿当成纯文字发出去。允许只有附件、没有正文的消息。
- 手机继续使用原 DSH 登录，二进制通过 Bot 的薄转接交给现有 Life skill；CLI 的 `assets.upload_local_attachment` 直接调用 Life 通用 `POST /api/assets`，不新增文件服务，不向手机下发 Life 代理凭据。
- Life 是原件权威，返回不可变资产版本、长度、MIME 与 SHA-256；Losna 只保留现有媒体执行缓存和入口绑定。图片进入原有识图链路，普通文件进入原有文件／工作上下文。
- 上传不代表已发送或已创建业务记录。消息只提交附件 ID，服务端核对所属伙伴并原子关联来源；已发送附件不能被另一条新命令直接复用。消息重试保持原命令和附件 ID。
- 点击附件可读取图片或保存原件；不在 WebView 中执行文件。读取沿用当前登录与来源可见性，遗忘后服务端拒绝访问，客户端快照撤回已打开的预览。
- 状态格式版本 3 将待确认消息的附件引用写入既有加密队列，兼容版本 1／2。未发送的文字及附件草稿跨旋转保留，但进程退出不承诺恢复；重新连接同一服务保留当前草稿。移除草稿引用不删除 Life 原件。

## 验证与发布边界

- 原生 Compose 393dp 与 320dp 页面渲染，检查首页、聊天、事项与附件上传区。
- UI 测试覆盖搜索恢复、草稿提示、小屏输入与菜单、历史阅读不被新消息打断、事项筛选、附件未完成禁止发送、只有附件允许发送、遗忘后预览撤回；另测本地日期跨年／夏令时和终态分类。
- Kotlin 核心与 HTTP 测试覆盖字节限额、上传／下载校验、原编号重试、状态升级兼容与跨联系人引用；跨仓库测试运行真实 Losna Product / Runtime、Life CLI 和共享上传客户端，对接合成回环资产 HTTP 服务，不调用生产或付费模型。
- Android 编译与 Lint、Losna 全量测试、Life `pnpm check` 分别记录。截图是合成资料的原生测试渲染，不冒充已安装的手机效果。
- 本轮仅代码与验证，未构建 APK、安装手机或部署服务。启用附件需同步发布 Losna 和 Life CLI；Life 现有 `/api/assets` 与数据库无需迁移，原 `mediaRoots` 需包含既有 Losna 媒体缓存目录。旧服务通过 capability 隐藏附件入口，文本聊天继续可用。
