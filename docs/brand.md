# Shadow 品牌规范

品牌中文名为“影”，英文名为 `SHADOW`，品牌标语：

> 掌控数据 · 洞察未来 · 守护自己

原始概念板保存在 [shadow-brand-board.png](assets/shadow-brand-board.png)。Android 图标和壳内横幅均从该概念板确定性裁切，不重新生成或改变原画。

## 主色

| 名称 | 色值 | 用途 |
|---|---|---|
| 夜影黑 | `#0D1117` | 页面和原生顶栏背景 |
| 深海蓝 | `#142031` | 卡片、输入框和浮层 |
| 月青 | `#18B8C8` | 主按钮、图表和状态 |
| 冰蓝 | `#A6F1FF` | 高亮文字与细描边 |
| 雾灰 | `#8B919C` | 次要信息和说明文字 |

## 资产

- `app/src/main/assets/brand/icon-master.png`：壳内使用的主图标裁切
- `app/src/main/assets/brand/banner.png`：应用中心品牌横幅
- `app/src/main/res/mipmap-*/ic_launcher.png`：Android 多密度启动图标
- `app/src/main/res/drawable/ic_stat_shadow.xml`：单色通知图标

## 界面规则

- 使用深蓝黑底色、低对比网格纹理和冰蓝细描边，不使用大面积高饱和色块。
- 中文品牌字可使用宋体/衬线体；业务数字和正文使用系统无衬线体。
- 模块卡片包含领域视觉、名称、简短说明和能力标签，卡片内部不复制业务页面导航。
- 原生顶栏只承担返回、回应用中心、刷新和连接设置，不覆盖各 Web 应用的业务操作。
- 新模块优先沿用月青色高亮，通过领域图形区分，而不是为每个模块引入完全不同的视觉体系。
