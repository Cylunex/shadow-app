# 手机成长手记

2026-11-06；起点 App `d2f732d`、Losna `8b9f110`。源码 0.14.0（24），仅开发与合成验证；未部署、构建 APK 或安装，手机仍为 0.12.0（22）。

## 缺口与参考

Product、Web 和 skill 已有成长手记，手机缺少入口。本轮接入既有的相处习惯和阅读看法，让用户查看依据并继续讨论，不新增学习规则、记忆库或人格权威。

## 实现与交互

- 聊天菜单按 `growth` 能力展示“成长手记”。当前人格的习惯显示有效范围与用户原话；阅读看法显示主题、观点、成熟程度，并可展开材料标题和逐字摘录。界面明确区分伙伴看法与亲身经历。
- 沿用 `behavior.activeHabits` 与 `reading.views`，各最多八条。跨会话手记不包含仅限当前轮次／话题的临时偏好；阅读看法沿用原有人格继承规则。空习惯不表示没有共同记忆。
- “带回聊天”将习惯及原话，或观点及材料摘录，追加到当前伙伴已有草稿。复用加密原子保存；合并超过 4000 字符时保留原稿并提示，保存失败不切换聊天。用户仍需编辑并发送，不自动发消息或修改记忆。
- 手记没有本地离线副本、历史分页、学习设置或直接编辑入口，也不是完整成长自传。修改／遗忘共享记忆继续使用原入口；本页只呈现现有有效内容。

## 协议与撤回

- 原 `GET growth?entryId=…` 增加 `generation / epoch / revision / unchanged`，握手增加 `growthSnapshots`。不传 `ifRevision` 仍返回完整习惯与看法，旧 Web／skill 保持原读取语义；手机连接只有 `growth` 的旧服务时每次读取完整内容。
- 新服务支持 64 位小写十六进制 `ifRevision`。修订对当前有效内容、入口、人格、服务代次和记忆 epoch 求哈希；未变化时返回 `unchanged:true` 和空数组，客户端保留已有完整内容、滚动位置及展开状态。
- 前台手记页面随既有约四秒轮询独立回读，即使没有 Product 事件也重新核对。当天习惯到期、学习设置变化和来源撤回不依赖新增事件；无法完成刷新时撤下旧手记并显示重试，避免把失效偏好继续呈现为当前适用。
- 人格／入口切换、服务重启、记忆 epoch 变化、授权失败或能力撤回清理旧投影。进入后台、离开页面和替换连接使在途请求失效；迟到响应不能恢复旧内容。新投影与已知人格／代次／epoch 不符时先刷新权威状态，不拼接两个版本。
- 本轮未改变 Web 的刷新节奏，也未为旧服务补充修订元数据。轮询存在网络与调度延迟，不声称即时推送；依旧依赖服务端的来源有效性检查。

## 验证与剩余范围

- 66 项 Kotlin 核心／真实 HTTP 合成集成测试通过，无跳过。覆盖条件读取、旧服务兼容、人格／入口／代次／epoch 隔离、晚到响应、网络和授权失败撤回、草稿追加及超长保护。实际启动 Losna Runtime、Product、SQLite，验证真实习惯、阅读证据、人格继承关闭和来源遗忘；全部内容为合成材料。
- 30 项 Android 单元／布局测试、Kotlin 编译、Debug Lint 通过；已检查 320dp 和双倍字体截图。覆盖依据展开、等值刷新保留展开状态、错误撤回旧文字、空状态和底部按钮可达。
- Losna 语法检查及全量 710 项 Node 测试通过，无跳过。新增测试验证无 Product 事件时的习惯到期、学习关闭、非法修订、人格／入口／epoch／代次变化。
- 持续事项 commitment 原生管理、浏览器接手仍未接入；实时推送、设备会话撤销、伙伴服务端音色及跨端播放仍是独立后续项。长期陪伴质量、实际模型对话和真机流程不由合成测试替代。
