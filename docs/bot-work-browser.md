## 参考与选择

以下一手资料在本轮联网核对；只借鉴机制，没有复制代码、引入外部账户或安装候选。

| 来源 | 采用 | 不采用 |
| --- | --- | --- |
| [Linear Search](https://linear.app/docs/search) | 检索完整事项内容，展示命中片段并打开原对象 | 不只过滤当前已加载摘要；不引入全局项目／成员搜索 |
| [Linear Filters](https://linear.app/docs/filters) | 搜索与状态筛选组合，空结果可清除条件 | 不引入复杂查询语言、视图管理或审批中心 |
| [Linear Pagination](https://linear.app/developers/pagination) | 有界页面与不透明游标，下一页承接同一查询 | 不迁移到 GraphQL；继续当前 HTTP Product v1 |
| [Grok Bot 文件与成果](https://docs.x.ai/grok-bot/files-and-results)、[Muse 产品设计](https://muse.ai/blog/how-we-designed-muse) | 旧工作可找回，成果留在原事项并可继续使用 | 不复制其运行时或把生成回复当作实际完成 |

选择事项检索是因为它补齐“次日／更久之后找到原委托并继续”的现有设计链路，不依赖新账号、通知服务或设备权限。持续事项原生管理和语音协同留给独立、可完整验证的后续工作。

## 协议与体验

- `workBrowse` 能力开启 `GET work-page?entryId=…&query=…&status=…&before=…&limit=…`。既有 skill 的 `GET works` 保持原响应和最近 100 项语义；新客户端连接旧服务仍使用快照，并明确提示范围。
- 搜索当前伙伴的全部有效事项，字面匹配完整目标、结果和计划正文；不搜索附件原件，也不把关键词当通配符或正则。服务端 Unicode 小写匹配，搜索词最多 200 UTF-16 字符。命中片段最多 282 字符，避免长结果只命中摘要之外却无从识别。
- 状态为全部／进行中／已结束，与原客户端分类一致；已结束包含 completed、cancelled、failed、excluded、interrupted、superseded。暂停显示原 paused 标记，不把“等待”或“模型停止”改成业务完成。
- 按原创建位置倒序分页，同一创建时间也不重复／漏项。游标绑定入口、搜索词、状态和内容修订；修订包含 Host generation、memory epoch、有效记录集合与工作版本。来源被遗忘时，即使没有重写 work，也从新列表、旧快照及首页在办计数撤回。
- `ifRevision` 条件读取在内容未变化时保留已加载页面和阅读位置；修订变化替换第一页。翻页遇到 409 清空旧页面并要求重新读取，不能把两个修订拼接。详情返回保留原查询、分页及列表位置；换伙伴清空条件与结果。
- 网络暂时失败保留已加载内容并显示重试；401／403、Host 重启、memory epoch 变化、能力撤回清除旧列表。离开事项相关页面或进入后台使在途请求失效，迟到响应不能恢复旧内容。事项不写入手机离线缓存。
- 每页手机 50 项、服务端上限 100；一次手机浏览最多 600 项，达到上限后提示收窄搜索。计数为当前查询全部匹配数，不把已加载数量当总数。继续／取消仍走原 workId、版本和幂等命令，成果仍沿用原权限和来源检查。

## 验证与限制

- 57 项 Kotlin 核心／真实 HTTP 合成集成通过。跨仓库测试实际启动 Losna Runtime、Product 和 SQLite，覆盖 123 项旧工作、特殊字符查询、三页读取、旧接口兼容、原详情打开及关联记忆遗忘后的游标撤回；模型与内容均为合成数据。
- 27 项 Android 单元／布局测试、`compileDebugKotlin` 与 `lintDebug` 通过；320dp、双倍字体截图已人工检查，测试覆盖从详情返回原阅读位置和修订变化后的旧行撤回。
- Losna 语法检查及 708 项 Node 测试通过，无跳过；新增专项覆盖 127 项分页、状态／完整正文搜索、入口和 owner 隔离、参数错误、Host 重启及来源遗忘。
- 检索沿用本机 SQLite 和现有工作存储，不新增索引权威。当前查询需要扫描当前入口的有效 work 并计算修订，大规模私有库的耗时、内存及轮询负载尚未实测，不宣称常量时间或无限规模。后续若有性能证据，再迁移同语义的索引实现。
- 本次不改变事项详情的 20 次执行、100 步计划、40 份成果窗口，不加入执行历史分页、跨伙伴搜索或完整文件内容搜索。设备与实际模型验收不在本轮完成范围。
